# Мой учебный проект

## Источник данных

Собственная таблица с повседневными задачами, содержащая информацию о выполняемых действиях, днях недели, статусах выполнения и категориях.


## Файлы проекта

В репозитории представлен основной файл:

- `data_v1.csv` — первоначальный набор данных, который в дальнейшем изменяется и сохраняется в виде отдельных версий через механизм GitHub Releases.

## Описание данных

Набор данных содержит информацию о повседневных задачах.

Используются следующие столбцы:

- **Пункт** — название задачи.
- **Дата** — день недели, на который запланирована задача.
- **Статус** — информация о выполнении задачи.
- **Категория** — группа, к которой относится задача.

## Результат

В итоговом наборе данных содержится 8 задач.

- Выполнено: 4 задачи (50 %).
- Не выполнено: 4 задачи (50 %).

## История версий данных

Для хранения и отслеживания изменений используется встроенный механизм GitHub Releases.

- **v1.0 — Исходная версия.** Создан первоначальный набор данных из 5 записей.
- **v1.1 — Расширение данных.** Добавлены 3 новые записи, общее количество увеличено до 8.
- **v2.0 — Структурирование данных.** Добавлен новый столбец «Категория», позволяющий классифицировать задачи.

Каждый релиз представляет собой отдельный снимок данных, позволяющий просматривать и скачивать соответствующую версию файла.

## Автоматизация через GitHub Actions

Для автоматизации проверки обновлений репозитория настроен workflow с использованием GitHub Actions.

Workflow запускается автоматически при добавлении изменений в ветку `main`.

В ходе выполнения workflow производится проверка успешного запуска и вывод сообщения:

`Отчёт готов`

Автоматизация успешно протестирована. Запуск workflow завершился с успешным статусом.
